# Ideenspeicher

Hier liegen Ideen und Konzeptentwürfe, über die noch nicht entschieden ist. Nichts in diesem
Verzeichnis ist verbindlich: Regeln stehen in `AGENTS.md`, Entscheidungen in [`docs/adr/`](../adr/README.md).

Eine Idee bleibt hier, bis sie verworfen wird oder in Tickets und gegebenenfalls ein ADR übergeht.
Dann bekommt sie den entsprechenden Status und einen Verweis darauf.

Ein Konzept nennt ein künftiges ADR nur als „neues ADR“, ohne Nummer. Die Nummer wird erst vergeben,
wenn das ADR angelegt wird; bis dahin wäre jede vorab genannte Nummer längst vergeben. Bestehende
ADRs werden wie überall mit Nummer zitiert.
